mlacker @VERSION@

This installs the mlacker terminal tracker together with the MLang toolchain it is built with (MLang @MLANG_COMMIT@) and the Mla VST3 plugins.

Default locations, the same as the build scripts use:

  • MLang toolchain: ~/.local (tools in ~/.local/bin)
  • mlacker: ~/.local/bin
  • Mla VST3 plugins: ~/.local/plugins/VST3

During the installation you are asked where to install each part (type a path or click Choose Folder…), and whether to add the MLang and mlacker tool directories to your shell profile if they are not on your PATH yet. To leave a part out, click Customize on the Installation Type step.

Requires a Mac with Apple silicon. Compiling MLang programs needs the Xcode Command Line Tools (xcode-select --install).
